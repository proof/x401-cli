# Contributing

Requires Node >= 22 and Yarn 4 (`corepack enable`).

```sh
yarn install
yarn check-all
```

`yarn check-all` formats, lints, type-checks, tests and runs publint; CI runs the same checks on
Node 22 and 24.

Fork the repository, branch off `main`, and keep each pull request to one change with a clear
description.

This project follows the
[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
